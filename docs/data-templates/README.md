# 주변상권·건물 상세 실제 데이터 템플릿

앱에 넣을 실제 정보를 정리하는 양식입니다. 정리해 주시면 개발자가 `src/constant/hongdaePlaces.ts`, `src/constant/buildingDetails.ts`에 옮깁니다. 나중에 서버 API가 생기면 같은 형태로 서버에서 받습니다.

| 파일 | 대상 |
| --- | --- |
| `hongdae-places.csv` | 주변상권 탭의 가게 (한 줄에 한 곳) |
| `building-details.csv` | 건물 상세·건물 카드 (한 줄에 한 건물) |

## 작성 규칙

- **직접 확인한 정보만** 적습니다. 모르는 칸은 비워 두면 앱에서 그 줄이 빠집니다.
- **운영 시간**은 요일 칸마다 적습니다.
  - 한 구간: `08:00-22:00`
  - 브레이크 타임: `11:00-15:00 17:00-21:00` (띄어쓰기로 구분)
  - 자정을 넘기면 끝 시각을 그대로: `18:00-02:00`
  - 쉬는 날: `휴무` / 24시간: `24시간`
- **"운영 중"·"운영 종료" 같은 상태는 적지 않습니다.** 앱이 지금 시각으로 계산합니다.
- **사진**은 직접 찍었거나 사용 허락을 받은 것만 씁니다. 블로그·지도 앱 사진은 쓰지 않습니다. 파일은 따로 모아서 전달해 주세요.
- **한줄소개**에 확인할 수 없는 평가·홍보 문구(예: "○○이 극찬한")는 넣지 않습니다.
- **확인한 날짜**는 앱에 "○월 기준, 변동될 수 있어요"로 보입니다.
- 위도·경도를 모르면 비워 두세요. 주소로 찾아 넣습니다.
