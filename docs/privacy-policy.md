# 【서비스명】 개인정보처리방침

【팀명】(이하 "팀")은 캠퍼스 지도·길찾기 앱 【서비스명】(이하 "앱")을 운영하며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 알려드리기 위해 작성했습니다.

> **요약**
> - 앱은 회원가입·로그인 없이 쓸 수 있고, 이름·연락처 같은 개인정보를 수집하지 않습니다.
> - 위치와 마이크는 지도·음성 검색 기능을 쓸 때만, 이용자가 허용한 경우에만 사용하며 팀의 서버로 보내거나 저장하지 않습니다.
> - 즐겨찾기와 최근 검색어는 이용자의 기기 안에만 저장되고, 앱을 삭제하면 함께 지워집니다.

---

## 1. 수집하는 개인정보

팀은 이용자를 식별할 수 있는 개인정보를 수집하거나 서버에 저장하지 않습니다. 회원가입, 로그인, 광고, 이용 행태 분석 도구도 사용하지 않습니다.

다만 앱의 기능을 제공하기 위해 아래 정보를 **이용자의 기기 안에서** 사용합니다.

| 구분 | 사용하는 정보 | 사용 목적 | 사용 시점 | 팀 서버 전송·저장 |
|---|---|---|---|---|
| 위치 정보 | 기기의 현재 위치 | 지도에 현재 위치를 표시하고 캠퍼스 안내에 활용 | 앱을 사용하는 동안, 위치 권한을 허용한 경우 | 하지 않음 |
| 마이크·음성 인식 | 음성 검색 시 말한 내용 | 말한 내용을 글자로 바꿔 장소 검색 | 음성 검색 버튼을 누른 경우에만 | 하지 않음 (녹음을 저장하지 않음) |
| 기기 내 저장 정보 | 즐겨찾기한 장소, 최근 검색한 장소, 온보딩 완료 여부 | 즐겨찾기·최근 검색 기능 제공, 처음 실행할 때만 안내 화면 표시 | 이용자가 해당 기능을 쓸 때 | 하지 않음 (기기 안에만 저장) |

위치와 마이크 권한은 허용하지 않아도 앱을 쓸 수 있습니다. 이때는 현재 위치 표시, 음성 검색 기능만 이용할 수 없습니다.

## 2. 외부 서비스 이용

앱은 기능 제공을 위해 아래 외부 서비스를 이용합니다. 이 과정에서 각 서비스 제공자가 자신의 방침에 따라 정보를 처리할 수 있습니다. 팀이 이용자의 정보를 이들에게 별도로 제공하지는 않습니다.

| 서비스 | 제공자 | 이용 목적 | 처리될 수 있는 정보 |
|---|---|---|---|
| 네이버 지도 SDK | NAVER Cloud Corp. | 지도 표시, 현재 위치 표시 | 지도 이용 정보, 위치 정보(위치 권한을 허용한 경우) |
| 기기 음성 인식 서비스 | Apple Inc.(iOS), Google LLC(Android) | 음성 검색 시 음성을 글자로 변환 | 음성 검색 시 말한 내용 |

- NAVER Cloud 개인정보처리방침: https://www.ncloud.com/policy/terms/privacy
- Apple 개인정보 처리방침: https://www.apple.com/kr/legal/privacy/
- Google 개인정보처리방침: https://policies.google.com/privacy?hl=ko

## 3. 개인정보의 보관 기간과 파기

팀은 개인정보를 서버에 보관하지 않으므로 별도로 파기할 정보가 없습니다.

기기 안에 저장되는 즐겨찾기, 최근 검색어, 온보딩 완료 여부는 아래 방법으로 언제든 지울 수 있습니다.

- 즐겨찾기: 앱에서 즐겨찾기(별)를 해제
- 최근 검색어: 검색 화면에서 항목별로 삭제
- 전체: 앱을 삭제하면 기기에 저장된 정보가 모두 지워집니다

## 4. 개인정보의 제3자 제공 및 처리 위탁

팀은 이용자의 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다.

## 5. 이용자의 권리와 행사 방법

이용자는 언제든지 다음을 할 수 있습니다.

- **권한 철회**: 기기 설정에서 앱의 위치·마이크·음성 인식 권한을 끌 수 있습니다.
  - iOS: 설정 › 【서비스명】
  - Android: 설정 › 애플리케이션 › 【서비스명】 › 권한
- **저장 정보 삭제**: 3항의 방법으로 기기에 저장된 정보를 지울 수 있습니다.
- **문의**: 개인정보와 관련된 문의는 아래 연락처로 보내주시면 지체 없이 답변드리겠습니다.

## 6. 만 14세 미만 아동

앱은 개인정보를 수집하지 않으므로, 만 14세 미만 아동의 개인정보도 수집하지 않습니다.

## 8. 방침의 변경

- 공고일: 【YYYY년 MM월 DD일】
- 시행일: 【YYYY년 MM월 DD일】
